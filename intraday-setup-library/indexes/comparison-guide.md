## 最容易混淆的决策边界

| 比较组 | 入场前就能观察的区别 | 不应如何区分 |
|---|---|---|
| [SET-0002](../setups/SET-0002.md) / [SET-0021](../setups/SET-0021.md) | 2冻结现金首五分钟与首柱方向；21必须有新闻/跳空盘前参与，使用开盘前已知PMH | 不能只因突破线价格不同就拆条；删去21的库存前提需重审合并 |
| [SET-0006](../setups/SET-0006.md) / [SET-0009](../setups/SET-0009.md) / [SET-0015](../setups/SET-0015.md) | 两段回撤第二次恢复 / 首次极浅暂停 / 普通回撤必要缩量与量恢复 | 不用后来哪个涨得快来区分 |
| [SET-0008](../setups/SET-0008.md) / [SET-0014](../setups/SET-0014.md) | 8要求旧趋势破坏后再测原极值；14要求首强反向冲击后的首弱回撤 | 不按最终是否成为全天反转来改标签 |
| [SET-0013](../setups/SET-0013.md) / [SET-0016](../setups/SET-0016.md) | 内包柱嵌套 / 固定水平被反复压向且拒绝距离缩短 | 一个小范围不自动具备两套前提 |
| [SET-0003](../setups/SET-0003.md) / [SET-0040](../setups/SET-0040.md) / [SET-0047](../setups/SET-0047.md) | 大量主动成交低位移后反向接力 / 主动冲击减少 / 支持持续但逐档小量缓慢磨过 | 大挂单、低量暂停与真实承接不能统称吸收 |
| [SET-0020](../setups/SET-0020.md) / [SET-0038](../setups/SET-0038.md) / [SET-0037](../setups/SET-0037.md) | 已结束前日尾部次日开盘 / 当前段伸展先失败 / 回旧价值并完成接受窗口后横穿 | 不将未来最终Profile当入场前分布 |
| [SET-0023](../setups/SET-0023.md) / [SET-0024](../setups/SET-0024.md) / [SET-0025](../setups/SET-0025.md) | 弱开盘跌势后收复 / 原趋势中的反向探测穿透后失败 / 双向平衡中的偏离衰退 | 不把所有穿VWAP或离VWAP远都当同一信号 |
| [SET-0042](../setups/SET-0042.md) / [SET-0043](../setups/SET-0043.md) | 已固定主动区被守住 / 逆旧趋势主动尝试被否认，价格反穿该区 | 相同Footprint配色不意味着相同交易方向 |
| [SET-0031](../setups/SET-0031.md) / [SET-0032](../setups/SET-0032.md) | 首个预案信息分支 / 后续新增内容改变净解释 | 第二段价格波动不自动证明第二段新信息 |
| [SET-0001](../setups/SET-0001.md) / [SET-0035](../setups/SET-0035.md) / [SET-0050](../setups/SET-0050.md) | 旧session边缘失败 / 当日IB首侧失败后反侧突破再回收 / 隔夜库存失败并反穿今日cash open | 不因都是开盘反转就省略各自必要历史顺序 |
| [SET-0048](../setups/SET-0048.md) / [SET-0049](../setups/SET-0049.md) | 因果同刻动态带且多半小时时点 / 早期收益符号只驱动最后半小时 | 参数、杠杆与止损版不能继承别版收益 |

这些条件可能在同一交易中重叠。一个样本可以多标签，但setup ID仍只按独立规则计数；复盘须先锁主假说，不能事后选最赚钱的标签。
