# 单笔与候选复盘模板

## 身份与版本

- 复盘ID、日期：
- Setup ID / 条目版本 / 来源规则版本：
- 主假说及相近ID；入场前区分依据：
- 市场、交易所/场所、合约/到期、数据商：
- 数据时区、UTC时间、交易日归属、cash/overnight分段：
- 数据粒度、成交方向/Delta reset/Profile/VWAP参数：

## 入场前记录（先保存，再看结果）

- 环境与必要前提，何时可知：
- 事前水平/事件/共识依据及时间：
- 行为顺序；必要/增强/否决条件分别记录：
- 原始截图/录屏文件、时间、权限与来源：
- 计划触发、订单类型、数量与取消时限：
- 分析失效、保护单、最大计划损失：
- 目标/管理依据和截止平仓时刻：
- 计划成本、点差、可借/限价队列/新闻延迟问题：

## 实际触发与执行

- 触发时间与价格；是否真正符合本条版本：
- 发单、成交和取消时间/价格/数量（可匿名）：
- 未成交、部分成交、滑点与延迟：
- 发生了什么新信息/流变化；当时判断记录：

## 持仓与退出

- 按时间列部分退出、止损移动、撤单与新单：
- 退出触发、实际成交、费用、借券/资金费：
- 是否同一session结束前全部退出：
- 实际结果（金额/点数/净R）；初始R定义：

## 分开评价三件事

- 识别：前提与顺序是否成立，证据是否完整：
- 执行：是否符合事先锁定规则，哪些偏离：
- 结果：正常规则亏损、未成立、执行偏离、来源歧义分别标记：
- 不因最终涨跌改写入场前规则；候选/no-trade也保存：

## 后续问题与版本变化

- 最值得验证的一项假设、对照和全样本纳入规则：
- 数据、成本、未成交、样本选择与前视风险：
- 不足证据/无法核验/不适用分别说明：
- 若规则改变，记录新版本与CHANGELOG，不覆盖原计划：
