# 实验模拟账户

`paper` 是版本化的执行实验。识别来源规则仍归 `recognition` 管理；这里的盈亏不能称为来源策略的复现绩效或真实交易结果。模块没有券商下单代码。

```python
from paper import PaperSimulator

sim = PaperSimulator()
result = sim.on_event(event, detections, event_seq)
snapshot = sim.snapshot()
restored = PaperSimulator.from_snapshot(snapshot)
```

`on_event` 接收一个行情事件产生的**完整检测批次**，返回 `orders`、`fills`、`account_events`、`decisions` 的增量行，以及 `account` 和当前 `positions`。`account()` / `account_snapshot()` 可直接读取账户。事件序号必须为递增正整数；重投最后序号不再次成交，更早序号拒绝。

运行器负责将输入进度和增量行在同一事务提交，周期保存版本化检查点；若事务失败，应丢弃修改过的实例，从已提交检查点加日志恢复。恢复验证 schema、执行配置和全部规则/算法注册哈希；变化后需要新运行回放。

`execution_profiles()` 通过可执行规则目录登记全部基础版与变体，包含来源、规则、算法及执行模型哈希。检测的来源/规则版本与登记不一致时拒绝开仓。候选或资料不足的检测不下单；一个批次内先触发后失效的最终状态也不下单。

默认 `next_quote_experimental` 模型：100,000 美元初始资金，每笔分配当时净值的 10%，最多五个仓位（待入场计数），整数股，一品种一仓位。报价按 ask/bid 加一 tick 不利滑点；每次成交手续费默认 0，明示保存。止损/目标阈值是实际入场价的 1%/2%；触及阈值后提交退出，下一条有效报价才成交，因此实际损益可能越过阈值。最长持有 60 分钟；交易日历的实际收盘前五分钟阻止入场并提交退出；日内净值下降 2% 锁定新入场并提交退出。

同批多空冲突全部阻断；同向以基础版、setup、变体、周期、检测 ID 排序选发起者，其余关联。有仓位或待入场时，同向关联、反向阻断。只有发起检测失效会提交结构退出。多个退出原因合并为一个待退出订单。

成交报价必须在命令后新收到，市场时间也晚于证据截止；过时、交叉、零价、部分资料或断线时不成交。入场有效窗口包含提交后第 60 秒；超过窗口取消。显式时钟推进截止、风险及收盘处理，不能成交。时钟之前收到而延后排队的报价不能补造成交；断线期间仓位、旧估值时间和待退出状态保持可见。

本次运行每个品种的首次session绑定执行venue。同symbol的另一venue session不能覆盖其日历、tick或当日状态，并保存`session_venue_mismatch`；异venue检测记录`execution_venue_mismatch`。只有匹配执行venue的报价能估值、触发价格退出及成交，订单、持仓与报价必须同源；异venue停牌/连接状态不能修改执行连接。需要切换数据来源时新建运行，不能把其他来源的价格静默填入现有账户。

`control("pause"|"stop"|"resume"|"start", seq, at)` 用于日志化控制，暂停/停止取消待入场，恢复/启动仅恢复新入场。退出仍等待行情。

`source_status(state, seq, at, symbols=None)` 提供不进入识别器的连接状态日志接口。断开、源错误、认证缺失与容量阻断会阻止已有待订单成交；CONNECTED 恢复连接而不取消人为暂停，也不消除交易停牌。运行器必须在日志里保存 `at`，以确保状态重放的风险截止时间一致。

`next_bar_proxy_experimental` 是独立研究模型：下一根完成柱的 open 为报价代理（此价格在柱完成后才用于模拟），忽略真实 quote；同样施加滑点和手续费。分钟柱实际到达晚于 60 秒时可通过独立配置扩大有效窗口。此模型不处理柱内路径、价差、流动性、部分成交和借券，不与报价账户合并评价。

资金运算使用 Decimal 和整数分。账户 `balance` 为初始资本加已实现净损益；多头和虚拟空头都锁定入场名义金额，空头卖出所得不能扩大可用资金。`available = balance - locked - reserved`；`equity = balance + unrealized`。估值使用最新有效报价的可平仓侧，保留数据时间。账本的 `amount_cents` 表示该事件的资金/资本变动含义；**只累计 `balance_delta_cents`** 重建余额，预约及锁定的余额增量为零，平仓为毛损益，手续费单独扣除。

内存只保留配置上限的近期成交、账本和终态订单；运行数据库保留完整增量记录。活动仓位和待订单不会截断，检测去重集合按交易日重置。
