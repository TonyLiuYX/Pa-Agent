学习路线与复盘练习

按数据条件选路线；阅读顺序不代表收益排名，也不建议一次交易全部50条。每条先读第4–7节，再遮住图右侧解释入场前能知道什么，最后读来源和失败部分。

路线一：仅有可靠OHLC和成交量

  • 先读 术语 的session、触发与失效；把数据时间戳、前日区间、半日和当日平仓边界写清楚。
  • 对照 两段回撤6、首次微回撤9、边界回测10。各自画“缺一个必要环节就不成立”的反例。
  • 比较 内包压缩13 与 固定水平压力16，固定来源版本，不用最后结果给突破贴标签。
  • 用 趋势柱失败17、再入19 的亏例练习：第一笔亏损仍须保留，后来的机会另记。
  • 区分 ORB2、PMH21 与 第二日消息28，分别冻结当时可知水平。

路线二：VWAP、分布与拍卖

  • 先统一VWAP重置、TPO bracket、Volume Profile算法和cash/overnight分段。
  • 比较 VWAP收复23、偏离失败24、平衡偏离25。为25收集完整失败/no-trade案例，现有文字不是图表核对。
  • 比较 VPOC flip4、TPO ledge33、ledge失败34，写出接受在当时如何识别。
  • 对照 前日尾部20、当前伸展38、旧VA横穿37。严禁用最终日内Profile标记早盘信号。
  • 37的“80%”只是名称。先复现两种接受口径和touch/clean差异，再讨论任何收益。

路线三：逐笔、DOM、Footprint

  • 先确认场所、合约、Bid/Ask分类、聚合、缺包及CVD reset；没有可靠数据时只学定义。
  • 比较 吸收3、耗尽40、能量改变39、慢磨47。分别记录真实成交、挂单变化、位移与速度。
  • 跳价41 同时有DAX成功和ES失败例；不要把薄区必然守住写成规律。
  • 比较 堆叠守区42、逆势失衡失败43、CVD背离44，画面颜色不能代替顺序。
  • 弱冲洗45 与 向下清仓46 涉及库存解释。将作者叙事与能直接观察到的流分开，动态视频仍待核验。

路线四：事件、跨市场和量化

  • 相对强弱27 与 先行IB30 要求同步市场数据；事后选领导市场会造成前视偏差。
  • 首轮新闻29、宏观预案31、多阶段信息32 分别记录新闻可获得时间、原始消息、共识证据与可成交报价。官方公告仅证实内容。
  • 复现 噪声带48 时先锁14日绝对幅度、半小时检查和风险版；复现 末半小时49 时先锁含隔夜的r1和15:30/16:00时钟。
  • 本库不含可运行策略回测。先做无前视的规则复现，再做样本外、成本、未成交和风险敏感性比较。

每轮学习可产出的材料

每轮选择两个相近ID，保存10–20个未经事后挑选的连续机会或候选；这个数量是练习规模，不是证明期望值的样本要求。每个留入场前截图、是否成立、触发价/成交价差、失效、平仓、规则偏离和未知。使用 复盘模板，整理一次规则定义修正，记入CHANGELOG，不按盈利单独筛选图例。
