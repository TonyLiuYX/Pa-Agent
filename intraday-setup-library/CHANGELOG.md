- 增加免费Alpaca IEX行情、无密钥演示、JSONL回放、本地运行服务和SQLite WAL持久化日志；识别、统一模拟账户及已提交事件在同一事务边界推进。
- 增加版本与哈希恢复检查、事件幂等、冲突隔离、检查点、容量降级与崩溃回放。新运行资料放项目外，真实订单和收费模型调用不在本轮执行范围。
- 注册50个基础版与34个变体的独立实验执行配置；共用资金、信号冲突仲裁、下一条有效报价成交、滑点、日终、最长持有及亏损限制单独审计。
- 新增中文五视图工作台、行情/关键位/逐条件证据、账户与待退出状态、默认隐藏结论的日志标注、能力矩阵及执行阻断记录；Lightweight Charts官方发布包本地保存并保留许可和署名。
- 因果同步等修复先升规则0.2.1：按当前股票截止时刻查找基准连续历史与disruption；SET-0019保留有效父路径依赖；SET-0041等2 tick跳价加入浮点精度容差。
- 复审后升规则0.2.2：Alpaca明确保存已完成交易日日历，缺最新日不再用更早完整日冒充前日；ATR、均量、同刻等按所需连续完整会话校准。显式history空列表清除旧资料，历史引用不能绕过缺日检查，旧事件未提供新元数据时保留兼容。
- 模拟品种首次session绑定执行venue，异venue session不覆盖日历，异venue报价不估值、触发价格退出或成交，异venue检测/状态不会关联或更改现有发起者/执行连接；同源限制和快照恢复增加回归。
- CLI增加多合成会话与IEX历史请求数，doctor显示实际配置，resume拒绝变更观察配置；独立回补分析只读取已提交原始资料，不创建模拟账户，缺对应真实session时明确阻断；默认64MiB/10000条输入上限，超限不会构造识别器。冻结评价拒绝容量阻断、缺上下文及完成标志不完整的分析资料，不产生误导评分。
- 工作台补齐订单历史、只显示已推进行情的回放图表与旧时点完整分页判断、手动SSE重连及当前研究JSON下载；已有标注默认折叠，防止泄漏盲标判断。异步写入仍等待提交且不自动重复。
- 工作台跨run身份切换清理旧账户分页、回放、所选证据及SSE游标，丢弃旧请求迟到响应；保留未提交标注草稿，仅人工已改草稿且数据来源改变时提示复核。同源新run和普通更新无需额外确认，仍不自动提交标注。
- 精确bar VWAP要求从实际cash open开始且资料连续完整；缓存截断后保留真实开盘锚点，缺开盘、盘前或累计资料的能力保持未知。截断时drive_recovery不再计算；覆盖统计增量保留累计触发。
- 新calendar到达时按真实收到时间清理前日候选，收盘未完整附incomplete_prior_session。停牌只由明确场所状态解除，网络重连、clock、gap、修订及calendar均保留既有停牌；已发判断保持因果截止边界。
- 严格检查整数序号、布尔状态、stream枚举和有限数值配置；特征注册表检查类型及真实提供路径。活动候选和仍可用父证据达到容量时停止；首次输出前限制证据ID预算并明确partial及截断原因，完整原始journal落库。
- JSON恢复校验算法、版本和容量政策，保留状态数组中的顺序。原始MarketEvent矩阵分层记录84图正向、50个基础版的100条已知为假核心谓词负例及68条变体补充阻断控制。变体边界更正为31个同品种/方向/共同周期机械边界、1个来源open时钟、1个注册周期选择；SET-0027公开价格代理可观察边界明确not_applicable。SET-0028提前触发改用同方向60s的event3对基础版event6，不能以variant空头event2作比较。原14项审计关联冻结输入与具体证据层。
- 检查点编码使用单次调用内的共享对象memo，恢复只池化不可变字符串，降低复制分配；保持v1 JSON及校验和字节兼容，旧前缀fixture证明相同后续识别。Store检查点仅序列化一次并分块计算UTF-8校验和，规范JSON读取快路径仍保留旧格式回退且拒绝非有限数字。这次编码优化不改变当时规则行为，跨核心恢复仍须版本校验；后续历史能力修复另登记0.2.2。
- 增加检查点与恢复后、临时对象作用域返回后的best-effort平台分配器维护；不强制GC、不清识别或账户状态、不更改SQL缓存或codec。环境不支持与调用错误仅进入独立健康遥测，不改变确定性日志、输出或账户；native零返回保留原语义。总览显示完成、待首次维护、环境不支持、错误或未报告及调用次数，精确后端和返回值保留在默认折叠详情。
- 候选5资源失败后增加v1流式规范编码（8192字符块，单次字符串转义缓存最多65536项/8Mi字符）及UTF-8外层缓冲，减少完整编码AST暂存；检查点独立短连接使用cached_statements=0，原子提交或回滚后关闭。soak恢复先释放旧Runner再创建新实例。session容量纯预检只在明确opt-in时启用，先于签名/状态修改检查完整记录及包含时间头的scalar预算，超限CapacityExceeded，不剪数据后续跑。进程环境证据安全保存白名单PYTHONMALLOC请求、启动标志和构建/平台信息，有效allocator保持unknown；规则0.2.2、schema及执行模型1.0.0保持，默认allocator与资源预算未调整。
- 评价增加阶段窗口、显式完整覆盖中的误报、冻结数据哈希及相关组切分锁；冻结评分必须核验实际run报告绑定的行情、完整规则集合和完整检测批次，逐行读取证据避免复制长期日志，拒绝布尔方向、非法时刻、混合版本及多来源分组中未声明来源的预测。
- 工作台分别呈现三阶段TP/FP/FN，无标签、版本错及容量限制有明确状态；完整标注范围默认不声明，争议或必要资料不足时禁用。暂停仅禁止新入场，已有持仓退出继续处理。
- 标注和运行控制收到异步受理后等待实际提交完成再提示成功；标注显示保存中、已保存或等待完成，超时不自动重发。新增延迟提交/超时fixture及采集中实际标注到报告复验。
- 行情混合frame中的状态和报价使用一致收到时间顺序；回调异常和队列积压进入显式状态。导出使用SQLite WAL只读事务快照、分块哈希并保持当前采集推进，原始输入、派生结果和账户保持同一已提交前缀。
